# School Tree Lab integration · 14 November 2026

Adds a public, bilingual spring-2027 prototype under `tree-lab/` and links it from both existing 3D worlds and the resource hub. Existing 3D logic and models are unchanged. The sample tree is not a real inventory record or completed activity.

Water-difference and activity-emissions charts use browser-local user records; estimates and measurement claims are differentiated. Air-quality effects and tree sequestration are not invented. Padlet links are navigation-only, never automatic posting/synchronization; November references are explicitly not spring destinations.

No private student information or credentials are included. Existing project artwork is preserved. Notes and entered tracker data stay in this browser; exports are user-controlled. Optional synthesized audio has no autoplay.

Validation: JavaScript syntax, local links, unique element IDs, feature logic checks and 10 existing XR tests passed. Desktop browser preview verified the landing and chart layouts, required evidence-field validation, a synthetic 10 L minus 4 L = 6 L water result, data-quality filtering and English/Turkish navigation. The music control changed Play → Stop → Play. Audible output and mobile viewport behavior have not yet been independently verified. Synthetic test records are browser-local and are not included in the published files.
