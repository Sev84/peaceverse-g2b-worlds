Türkçe

İki 3B dünya, aylık öğrenme görevleri, dört dil, doküman merkezi ve öneri panosu bu sürümde bir aradadır. Mevcut öğretmen sitesi hesapla puan kaydı, dosya yükleme ve öneri onayı sağlar; erişimi şu anda site sahibine özeldir.

GitHub Pages yayını 19 Ekim 2026 tarihinde tamamlandı. Öğrenci bağlantıları aşağıda verilmiştir. Pages sürümünde puanlar, profil ve öneri taslakları yalnızca kullanılan tarayıcıda saklanır. Ortak teslimler öğretmenin belirlediği Padlet alanında yapılır. Onaylı ürünler yayın kataloğuyla eklenir; özel öğretmen sisteminden otomatik eşitleme henüz yoktur.

Dokümanlardaki V2 ve V3 ekranları önceki aşamaların kaydıdır. Son 3B modeller V3, web arayüzü V4’tür. Müzikli demo önceki modelin çevrimdışı renderıdır. Gerçek zamanlı VR kaydı değildir. Test tarayıcısı WebGL desteklemediğinden VR gözlük ve telefon AR kontrolü uygun cihazda yapılmalıdır.

GitHub Pages uygulamasını desteklenen tarayıcıda ana ekrana ekleyebilirsiniz. Daha önce açılan sayfalar ve sahne dosyaları çevrimdışı kullanılabilir; Padlet ve indirme dokümanları internet gerektirir. Tarayıcı verileri temizlenirse kişisel puanlar ve taslaklar silinir.

English

This release brings together both 3D worlds, monthly tasks, four languages, a document library and a suggestion board. The existing teacher site supports account-based progress, uploads and suggestion moderation; it currently remains owner-only.

GitHub Pages was published on 19 October 2026. Student links are listed below. On Pages, scores, profiles and suggestion drafts remain in the current browser only. Shared submissions use the teacher’s Padlet. Approved works are added through the published catalog; automatic synchronization from the private teacher system is not yet available.

V2/V3 documents record earlier stages. The latest models are V3 and the web interface is V4. The music demo is an offline render of an earlier model, not a live VR recording. This test browser lacks WebGL; a compatible headset and phone are still needed to verify VR and AR.

Supported browsers can add the Pages app to the home screen. Previously opened pages and model files can work offline; Padlet and document downloads require internet. Clearing browser data removes local progress and drafts.

Documentele V2/V3 descriu etape anterioare. Modelele finale sunt V3, interfața web este V4. Videoclipul muzical este o randare offline a unui model anterior, nu o înregistrare VR în timp real. Browserul de test nu are WebGL; VR și AR trebuie verificate pe dispozitive compatibile. Ștergerea datelor browserului elimină progresul și ciornele locale.

Сайт GitHub Pages опубліковано 19 жовтня 2026 року. Посилання для учнів наведено нижче. На Pages бали, профілі й чернетки зберігаються лише в поточному браузері.
